# PRD

Esta carpeta documenta el producto actual y las decisiones que afectan su evolucion.

| Documento | Contenido |
| --- | --- |
| [definicion-producto.md](definicion-producto.md) | Problema, propuesta de valor, usuarios, alcance, limites y metricas aun no definidas. |
| [recorridos-y-requisitos.md](recorridos-y-requisitos.md) | Recorridos de usuario, requisitos funcionales/no funcionales y criterios observados. |
| [decisiones-producto.md](decisiones-producto.md) | Decisiones implementadas, inferencias y decisiones abiertas que requieren owner. |

## Regla de evidencia

- **Confirmado:** declarado por manifest/README o implementado por codigo.
- **Inferido:** lectura razonable del comportamiento, sin decision escrita del producto.
- **Pendiente:** pregunta que el repositorio no puede resolver.

No convertir una inferencia en decision confirmada sin validacion de un owner de producto.
